## 状态定义

- `未开始`：尚未进入实施。
- `进行中`：已经实施，但还没有完成全部验收。
- `部分完成`：存在非阻断项未完成，不允许进入依赖它的下一节点。
- `阻塞`：存在当前无法消除的外部或技术阻断。
- `已通过`：所有阻断级验收项均有证据且通过。
- `已失效`：后续回归发现该节点不再满足验收标准；使用新记录说明原因。

## 文件命名

```text
M编号-YYYYMMDD-简短名称.md
```

例如：

```text
M0-20260908-Codex双向通信验证.md
```

## 记录规则

1. 只有实际执行过的验证才能写“通过”。
2. 不用计划内容代替验证证据。
3. 失败结果也要记录，避免重复走已经证伪的路径。
4. 节点通过后仍保留已知限制，不为了结项隐藏风险。
5. 后续结果发生变化时新增记录，不修改旧记录中的历史事实。
