## 交付决定

- 冻结 `0.1.8` 为首个课程学员使用版。
- GitHub 作为源码、说明和更新渠道，不作为学员主要安装入口。
- 学员主要入口改为 Windows ZIP 工具包：解压后先双击“一键安装”，此后双击“一键启动”。
- 后续功能与体验需求进入下一版本，不继续扩大本次交付范围。

## 本节点交付物

- 产品发布型 `README.md`：真实产品首图、一句话价值、3 个核心特性、快速开始、前后效果和演示视频。
- `docs/安装与使用.md`：面向无开发经验学员的完整安装、使用、更新与排错说明。
- `一键安装.cmd`、`一键启动.cmd` 与 `scripts/install.mjs`。
- 自带官方 Node.js 24.21.0 运行环境和依赖的 Windows 发布包。
- 插件商品页真实截图与正式个人插件刷新安装。
- 新增发布包验收用例 TC-100 至 TC-106。

## 已知限制

- 学员仍需自行安装并登录 Codex Windows 客户端；工具包不能替代 Codex。
- 页面样式通过 Tailwind CDN 加载，使用时需要正常联网；Codex 图片生成本身也需要网络。
- 当前只交付 Windows x64 工具包，不包含 macOS 版本。
- 每个批次最多向内置图片生成能力提交 5 张参考图。
- 本节点只证明交付包和安装链路通过；此前标为待真实生图复验的细分体验项仍保留原历史状态，不用本节点覆盖。
