## 真实链路验证

1. 审核台为返修批次创建随机运行令牌。
2. 插件读取两镜头完整脚本、文字返修意见和唯一勾选的人物资产路径。
3. Codex 内置图片生成能力只接收该人物资产和本次提示词，生成 2 列 × 1 行宫格。
4. MCP 工具依次回报生成、提交状态，并将结果回填为 v3。
5. 页面自动显示 v3、返修来源和“已自动回填”。
6. 页面切换 v1 验证历史只读，再回到 v3。

## 已知限制

- M1 仍需用户在每个批次首次生成时手动新建一个独立 Codex 任务并粘贴任务指令；页面一键创建任务属于 M2。
- 同批返修可以复用同一任务。工具和提示词不会重新附带历史宫格，但任务历史中的旧图无法做到数学意义上的不可见。
- 插件当前引用本机项目绝对路径，适合个人本地使用；公开上架前要改造成可移植安装包。
- 400px 窄屏保留左右同屏，信息密度较高；更舒适的窄屏视觉优化属于 M3，不阻断核心操作。
- 当前备份 JSON 不打包图片文件；自包含备份属于 M3。

## 遗留风险

- Codex 服务偶发 WebSocket 超时时会自动回退 HTTPS；本次未阻断插件工具调用。
- Tailwind 样式通过 CDN 加载；离线环境可能缺少样式，后续产品化应改为本地构建产物。
