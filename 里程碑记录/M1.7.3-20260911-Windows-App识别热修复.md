# M1.7.3 · Windows App 识别热修复

- 状态：已通过
- 验收日期：2026-09-11
- 对应计划：../迭代计划.md

## 问题与根因

- `v0.1.9` 已修复批处理闪退和 `CODEX_HOME`，但仍假设 Windows App 一定会把 `codex.exe` 暴露到 PATH、独立安装目录或 `manual-cli`。
- 干净电脑可以正常打开 ChatGPT/Codex Windows App，却尚未生成这些命令行入口，导致安装器把“找不到可执行入口”误判成“未安装客户端”。
- Windows App 自身另有插件专用组件，并在应用包中包含 Codex 组件；旧安装器未覆盖这两种形态。

## 本节点交付物

- `v0.1.10` Windows 学员工具包。
- 安装器优先识别当前用户 `.codex/plugins/.plugin-appserver/codex.exe`。
- 如果插件组件尚未生成，自动定位已安装的 ChatGPT/Codex Windows 应用包，并把内置组件准备到工具包 `runtime/codex-cli.exe` 后完成安装。
- 明确工具包可放在任意本地目录，不需要放进 App 安装目录；位置变化后重新安装即可。
- 新增无 PATH、无独立 CLI、无 `manual-cli`、无 `plugin-appserver` 的 Windows App 隔离安装测试。
