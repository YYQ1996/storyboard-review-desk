# M1.7.2 · 学员安装包可靠性热修复

- 状态：已通过
- 验收日期：2026-09-11
- 对应计划：../迭代计划.md

## 问题与根因

- `v0.1.8` 发布包中的 Windows `.cmd` 文件只有 LF 换行，`cmd.exe` 会把多行错误解析，导致双击安装窗口一闪而过。
- 安装器调用 Codex 插件命令时未显式传入 `CODEX_HOME`；部分干净电脑无法自动解析配置目录，插件刷新失败。
- 原发布验收只直接运行了 `install.mjs`，没有通过 Windows `cmd.exe` 原样执行发布包入口，因此未覆盖第一类故障。

## 本节点交付物

- `v0.1.9` Windows 学员工具包。
- 构建阶段强制把 `一键安装.cmd`、`一键启动.cmd` 规范为 CRLF。
- 安装器创建并向全部 Codex 子命令显式传入当前用户的 `CODEX_HOME`。
- 安装器兼容 PATH、新版独立安装目录和桌面版内置 CLI 位置。
- 安装过程写入 `install-log.txt`；成功和失败窗口都会保留。
- 新增 Windows 安装器端到端自动测试。
