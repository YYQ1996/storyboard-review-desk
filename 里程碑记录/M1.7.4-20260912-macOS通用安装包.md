# M1.7.4 · macOS 通用学员安装包

- 状态：验证中
- 验收日期：2026-09-12
- 对应计划：../迭代计划.md

## 目标

为 Apple 芯片和 Intel 芯片 Mac 学员提供单一安装包，并保持与 Windows 版相同的本地审核台、个人插件和批次回填能力。

## 本节点交付物

- `分镜审核台-v0.1.10-macOS-universal.zip`。
- Apple Silicon `arm64` 与 Intel `x64` 两套内置 Node.js 运行环境。
- `一键安装.command`、`一键启动.command` 与 macOS 小白使用说明。
- macOS Codex 组件复用与 OpenAI 官方 CLI 自动安装回退。
- ZIP 架构、权限、数据隔离和绝对路径自动验证。
