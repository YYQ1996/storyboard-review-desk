# 分镜审核台

**把分镜脚本、参考资产与 Codex 串成一条可审核、可返修、可回填的宫格工作流。**

`Windows` · `Codex 个人插件` · `本地数据` · `v0.1.8`

<img src="docs/images/app-overview.png" alt="分镜审核台产品界面" width="100%" />

</div>

## 它能帮你做什么

分镜审核台面向 AI 短剧创作者：导入结构化分镜脚本，按批次选择镜头与参考资产，把任务交给 Codex 生成宫格图，再在同一页面批注、返修、通过并导出终版脚本。你不需要手工搬运每一轮图片和文本，也不会把上一批参考图混进下一批。

| 批次隔离生成 | 所见即所得审核 | Codex 自动回填 |
| --- | --- | --- |
| 每批独立任务，最多 9 镜、15 秒、5 张参考图 | 宫格与右侧分镜逐镜联动，批注集中汇总 | Codex 读取本批上下文，生图后自动回填新版本 |

## 最快开始

> **下载 Windows 工具包并解压 → 双击 `一键安装.cmd` → 重启 Codex → 双击 `一键启动.cmd`**

[下载最新版工具包](https://github.com/YYQ1996/storyboard-review-desk/releases/latest) · [查看完整安装说明](docs/安装与使用.md)

工具包已经包含运行环境和插件依赖。学员不需要安装 Git、GitHub、Node.js、Python，也不需要打开命令行；只需提前安装并登录 Codex Windows 客户端。

## 第一次使用

1. 双击 `一键启动.cmd`，浏览器会自动打开审核台。
2. 导入分镜脚本并确认成片画幅；系统会自动引导创建第一批次。
3. 上传本批人物、场景、道具参考图，确认勾选不超过 5 张。
4. 点击“创建 Codex 任务指令”，在 Codex 中新建任务并粘贴发送。
5. 推荐选择 `GPT-5.6 Luna`、低推理强度；等待宫格图自动回填。
6. 点击宫格定位镜头，集中填写批注；返修满意后通过本批并继续下一批。

每个批次必须新建一个 Codex 任务；同一批次的返修可以留在该任务中继续。

## 这一版已经覆盖

- 结构化脚本导入，支持连续镜头共用上一级场景。
- `16:9` / `9:16` 画幅锁定与对应宫格生成。
- 人物、场景、道具参考资产上传、解码校验、压缩与批次隔离。
- 默认选取前 9 镜且累计不超过 15 秒，下一批继承上批参考资产。
- 宫格图、分镜脚本、点击热区统一镜号；支持批内合并或新增镜头。
- 集中批注、脚本返修、版本回填、仅删除最新批次、终版脚本重编号导出。
- 操作记录导出与重复历史图片回填拦截。

## 数据与隐私

脚本、参考图、宫格版本和操作记录只保存在工具包目录下的 `data/`。仓库与发布包都不包含开发者的项目数据。更新或移动工具前，请先点击页面顶部“导出备份”，或复制整个 `data/` 文件夹。

## 遇到问题

- 页面提示“无法访问”：确认 `一键启动` 的黑色窗口仍保持打开。
- Codex 找不到插件或提示路径不一致：关闭 Codex，重新双击 `一键安装.cmd`，再启动 Codex。
- Codex 无法连接审核台：先启动审核台，再发送任务指令。
- 图片无法上传：按页面一次性列出的错误处理后重新上传；旧版本问题图需删除后重传。
- 参考图超过 5 张：保留在资产库即可，只勾选本批最关键的 5 张。

完整排查方式见 [安装与使用说明](docs/安装与使用.md#常见问题)。
