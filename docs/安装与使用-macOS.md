# 分镜审核台：macOS 安装与使用

这份说明面向不使用 GitHub、命令行或开发工具的学员。工具包同时支持 Apple 芯片和 Intel 芯片 Mac。

## 安装前准备

1. 安装并登录最新版 ChatGPT/Codex macOS App，至少正常打开一次。
2. 第一次安装时保持联网；如果系统没有可供安装器使用的 Codex 组件，工具会自动调用 OpenAI 官方 macOS CLI 安装器。

不需要另外安装 Node.js、Python、Git，也不需要把工具包放进 ChatGPT/Codex 的应用目录。

## 一键安装

1. 下载 `分镜审核台-v0.1.10-macOS-universal.zip`。
2. 双击 ZIP，使用 macOS 自带的“归档实用工具”完整解压。
3. 工具包可以放在“下载”“桌面”或任意本地文件夹；建议移动到固定位置后再安装。
4. 第一次运行时，按住 Control 点击或右键点击 `一键安装.command`，选择“打开”。
5. 看到安装成功后，完整退出并重新打开 ChatGPT/Codex App。

安装完成后不要移动、改名或删除整个工具包文件夹。如果需要换位置，移动后重新运行 `一键安装.command`。

## 每次启动

双击 `一键启动.command`。系统会用默认浏览器打开：

```text
http://127.0.0.1:43127/
```

使用期间请保持 Terminal 窗口打开。结束使用时关闭窗口或按 `Control + C`。

如果审核台已经在运行，再次双击启动只会打开页面，不会重复启动或显示端口占用错误。

## 在 Codex 中执行批次

1. 在审核台创建批次并点击“创建 Codex 任务指令”。
2. 回到 ChatGPT/Codex App，新建“工作”类型的本地任务。
3. 选择“不使用项目 / 无项目”，不要选择云端任务。
4. 粘贴审核台生成的完整指令并发送。
5. 每个新批次新建一个任务；同批返修留在原任务中继续。

## 常见问题

### macOS 提示无法验证开发者

当前测试包没有 Apple Developer 签名。请按住 Control 点击或右键点击 `.command` 文件，选择“打开”，再在确认框中选择“打开”。不要关闭系统安全保护。

### 双击后提示没有权限

请确认使用 macOS 自带的“归档实用工具”解压，没有通过网盘在线预览或第三方工具直接运行。若仍失败，请把提示截图发给老师，不要自行修改工具包。

### 安装时提示找不到 Codex

请确认 Mac 已联网，ChatGPT/Codex App 已安装、登录并至少启动过一次。安装器会自动尝试安装 OpenAI 官方 Codex CLI；失败详情保存在工具包根目录的 `install-log.txt`。

### 浏览器显示无法访问

确认 `一键启动.command` 对应的 Terminal 窗口仍开着，等待两秒后刷新页面。

### 数据保存在哪里

项目数据仍保存在工具包根目录的 `data/`。更新或移动工具包前，请先在页面顶部导出备份，并额外复制 `data/` 文件夹。
