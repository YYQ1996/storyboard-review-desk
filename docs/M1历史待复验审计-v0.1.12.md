# M1～M1.10 历史待复验审计（基于 v0.1.12）

> 审计日期：2026-09-15  
> 原则：历史记录只追加、不改写。本文件判断旧待验收项在当前稳定版中的覆盖情况，并把仍需真人或真机确认的事项汇总到 M2。

## 审计结论

`v0.1.12` 已通过后续实现和自动测试覆盖大部分早期技术缺口，但“测试覆盖”不等于“当时的用户复验已经发生”。仍未闭环的主要风险集中在：双平台干净电脑安装/升级、真实 Codex 生图链路、生成耗时与中文文字质量、视觉点击定位和后台回填时的真实输入体验。

## 合并后的待复验清单

### P0：M2 未取得证据前不得宣布通过

1. Windows 干净电脑首次安装、插件识别、启动、真实首版生成、自动回填和导出。
2. Windows 从 `v0.1.11` 覆盖升级到 `v0.1.12`，旧项目与图片不丢失。
3. Apple Silicon Mac 首次安装、Gatekeeper 放行、插件识别、真实生成、返修、回填、导出和重复启动。
4. 批内合并/新增镜头后，生图脚本、宫格镜号、右侧脚本和点击定位在真实生成结果中一致。

### P1：需真实用户操作确认

1. 后台 Toast/回填不抢审核意见输入焦点，草稿、光标和滚动位置保持。
2. 导入后的首批引导、资产默认继承、页面场景父级和批次选择体验。
3. 6～14 项资产在两个平台都实际生成 5 张同类型索引板并完成回填。
4. 多批次导出、备份、操作记录和重启恢复。

### 已知模型或平台限制

- 宫格中的中文文字由图片模型绘制，存在错字、漏字或镜号不准确的概率，需要人工审核和返修。
- 生成耗时含 Codex 排队与图片模型时间，产品只能缩短本地准备链路，不能承诺固定秒数。
- 同批返修复用同一 Codex 任务时，任务历史仍存在；产品可限制主动参考范围，但不能提供数学意义的上下文清除。
- macOS 包未使用 Apple Developer 证书签名，首次打开需要用户手动放行。
- 页面样式仍从 Tailwind CDN 加载，完全离线首次打开可能样式不完整。

- 新证据写入 `里程碑记录/evidence/M2/`，文件名含平台、日期和测试编号。

- 证据补齐后新增 M2 补充记录；不得把本审计结论回填到旧节点文件中冒充当时已通过。
