# 分镜审核台：安装与使用

这份说明面向第一次接触本工具的学员。全程不需要 GitHub、Git、Node.js、Python，也不需要输入命令。

## 安装前只需要准备一件事

请先在 Windows 电脑上安装并登录 Codex 客户端。分镜审核台的宫格生成与自动回填依赖 Codex；工具包本身不包含 Codex，也不会要求你填写图片模型 API Key。

支持环境：64 位 Windows 10 / 11。

## 一键安装

1. 下载 `分镜审核台-v0.1.9-Windows.zip`。不要继续使用旧版 `v0.1.8` 安装包。
2. 右键压缩包，选择“全部解压”。不要直接在压缩包预览窗口里运行文件。
3. 打开解压后的 `分镜审核台-v0.1.9-Windows` 文件夹。
4. 双击 `一键安装.cmd`。
5. 看到“安装完成”后关闭窗口，并完整退出、重新打开 Codex。

安装脚本只做三件事：检查 Codex、部署“分镜审核台”个人插件、写入当前工具包的正确路径。它不会上传你的本地文件。

安装窗口会在成功或失败后停留。若安装失败，请拍摄窗口中的完整文字，或发送同目录自动生成的 `install-log.txt`；不需要让 Codex 临时修改安装包。

## 每次启动

双击 `一键启动.cmd`。请保持弹出的黑色窗口打开，浏览器会自动进入：

```text
http://127.0.0.1:43127/
```

结束使用时，关闭这个黑色窗口即可停止服务。

## 完整工作流

### 1. 导入脚本

点击“导入分镜脚本”，选择 `16:9` 或 `9:16` 成片画幅，再粘贴结构化分镜脚本。导入后画幅会锁定，系统自动打开第一批次创建窗口。

### 2. 创建批次

系统默认从待分配镜头中向后选择：最多 9 镜，且累计时长不超过 15 秒。确认镜头后创建批次。

### 3. 添加参考资产

上传人物图、场景图或道具图。新上传图片默认勾选；单个批次最多向生图能力提交 5 张参考图。下一批默认沿用上一批的勾选结果，你仍可手动调整。

### 4. 交给 Codex

点击“创建 Codex 任务指令”，复制页面生成的完整指令。然后按下面的方式新建 Codex 任务：

1. 回到 Codex 首页，点击“新建聊天 / 新建任务”。
2. 类型选择“工作（ChatGPT Work）”，不要选择普通“聊天”。分镜审核台需要在工作任务中调用个人插件、生图并自动回填。
3. 项目选择“不使用项目 / 无项目”。本工具不依赖代码仓库，也不需要选择分镜审核台源码或工具包目录。
4. 如果界面询问运行位置，选择“本地（Local）”，不要选择“云端（Cloud）”。审核台运行在当前电脑的 `127.0.0.1`，云端任务无法访问。
5. 推荐选择 `GPT-5.6 Luna`、低推理强度，粘贴完整指令并发送。

如果当前停留在某个已有项目里，也可以先回到首页再新建无项目任务。没有必要为每个批次新建项目；只需要为每个批次新建一个独立任务。

Codex 会读取本批镜头、画幅和勾选资产，调用内置图片生成能力，并把生成结果自动回填到审核台。

### 5. 审核与返修

点击宫格中的任意格，可以定位到右侧对应分镜。镜头旁批注会统一汇总到底部“审核批注”区域。提交返修后，Codex 会先修改分镜脚本，再严格使用新版脚本生图。

返修允许在当前批次内合并或新增镜头。历史批次不会因此被重排；创建下一批时，系统会从最新批次的最后一个镜号继续编号。

### 6. 通过与导出

确认无误后点击“通过本批”。全部批次完成后导出终版脚本；如全量镜号存在重复或缺口，导出副本会自动连续重编号。

## 更新版本

1. 在旧版本顶部点击“导出备份”，并额外复制旧工具包的 `data/` 文件夹。
2. 下载并解压新工具包。
3. 把旧版 `data/` 复制到新版根目录。
4. 双击新版 `一键安装.cmd`，然后重启 Codex。

不要直接覆盖仍在运行的旧工具目录。

## 常见问题

### 双击启动后浏览器显示“无法访问”

等待 2 秒后刷新。如果黑色启动窗口已经关闭，请重新双击 `一键启动.cmd`；窗口必须在使用期间保持打开。

### 一键安装提示“未找到 Codex”

先安装并至少启动登录一次 Codex，然后重新运行安装脚本。如果已经安装，确认使用的是 Windows 桌面版。

### 双击一键安装后窗口一闪而过

先确认下载的是 `v0.1.9` 或更新版本，并且已右键“全部解压”。`v0.1.9` 已把 Windows 批处理入口固定为 CRLF 换行，正常情况下无论成功还是失败都会保留窗口。若仍闪退，请重新下载发布包并核对 SHA256，避免使用网盘或浏览器缓存中的旧版 `v0.1.8`。

### 安装提示 failed to resolve CODEX_HOME

`v0.1.9` 会创建并显式传入当前用户的 Codex 配置目录，不需要手动设置环境变量。若仍出现此错误，请发送工具包根目录的 `install-log.txt`，不要直接修改 `install.mjs`。

### Codex 读不到“分镜审核台”技能

完整退出 Codex，重新双击 `一键安装.cmd`，确认显示安装成功后再启动 Codex。更新或移动工具包目录后也要重新安装一次，让插件记录新路径。

### Codex 提示无法连接审核台

先双击 `一键启动.cmd`，确认浏览器能打开审核台，再回到 Codex 重新发送任务指令。

如果使用的是云端任务，请重新新建一个“工作”类型的本地任务。云端无法访问当前电脑上的 `127.0.0.1` 审核台。

### Codex 新建任务时应该选聊天还是工作

选择“工作（ChatGPT Work）”。普通“聊天”适合快速问答，不适合这套需要个人插件、生图和自动回填的完整流程。

### 是否需要新建项目或选择文件夹

不需要。推荐选择“不使用项目 / 无项目”。不要选择分镜审核台源码或工具包目录；这些文件只用于运行工具，不是每批宫格图的工作素材。

### 上传图片失败

审核台会在上传阶段一次性检查所有图片并列出问题。请重新导出损坏图片，推荐使用标准 JPEG 或 PNG；删除旧问题资产后再上传。

### 参考图很多，为什么只能勾选 5 张

Codex 内置图片生成能力单次最多接受 5 张参考图。资产可以全部保留在库中，但每批只选择最关键的 5 张。

### 数据保存在哪里

都在工具包根目录的 `data/`：

```text
data/
├─ project.json
├─ assets/
├─ versions/
├─ backups/
└─ logs/storyboard-review.jsonl
```

需要反馈问题时，可以点击顶部“导出操作记录”，并说明操作到哪一步；不要公开发送包含隐私内容的项目备份。
