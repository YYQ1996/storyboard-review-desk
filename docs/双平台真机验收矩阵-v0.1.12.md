## 1. 验收原则

- “源码测试通过”“安装包结构正确”和“真实干净电脑跑通”是三类不同证据，不能相互替代。
- Windows 与 macOS 必须分别完成整条链路；不能用一端结果推定另一端。
- 每次真机验收记录设备、系统、芯片、Codex 版本、安装包 SHA256、产品版本和时间。
- 首版生成与返修必须调用真实 Codex 内置图片生成并自动回填；演示数据、手工复制图片或模拟接口不算通过。
- 发现问题时保留截图、`install-log.txt`、导出的操作记录、运行 ID 和版本 ID。日志中涉及创作内容或本地路径时，不公开上传。

- `v0.1.12` Release 的两个 ZIP 与本地 SHA256 一致。
